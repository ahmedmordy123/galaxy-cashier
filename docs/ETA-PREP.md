# الفاتورة الإلكترونية (ETA) — مصر

## الحالة الحالية في CASR

- جدول `EtaDocument` جاهز في قاعدة البيانات لحفظ طوابير التصدير.
- إعداد `eta_enabled=false` في Settings.
- **لم يُفعَّل الربط الحي** مع منظومة الفاتورة الإلكترونية لأنه يحتاج:
  - تسجيل الممول على بوابة مصلحة الضرائب
  - Client ID / Secret
  - شهادة توقيع إلكتروني

## الخطوات اللاحقة عند التفعيل

1. تفعيل `eta_enabled=true` من الإعدادات
2. إدخال بيانات API في بيئة Electron / `.env`
3. عند تأكيد فاتورة بيع: إنشاء سجل `EtaDocument` بحالة `PENDING`
4. خدمة خلفية ترسل JSON حسب مواصفات ETA وتحدّث `uuid` / `status`

## ملاحظة

الهيكل موجود؛ الربط الحي موجة منفصلة بعد استقرار بيانات المحل والضريبة.
