# دليل الاستخدام السريع — CASR

## تشغيل
1. شغّل `start.bat` أو ملف `CASR 1.0.0.exe`
2. افتح http://localhost:3001
3. دخول: `admin` / `admin123` — **غيّر كلمة المرور فورًا**

## البيع اليومي
1. المبيعات → فاتورة جديدة
2. امسح الباركود أو ابحث بالاسم
3. أكّد الفاتورة واطبع

## الشراء والمخزون
1. المشتريات → فاتورة جديدة → أكّد (يحدّث الكمية ومتوسط التكلفة)
2. حركة المخزون: تحويل بين المخازن
3. الجرد: أدخل الكميات الفعلية واحفظ التسوية

## النسخ الاحتياطي
الإعدادات → نسخ احتياطي الآن / استعادة من القائمة

## التقارير
التقارير → تحليل المبيعات / الربحية / حركة صنف
