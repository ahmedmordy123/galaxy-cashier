## قرارات المسارات

| | |
|--|--|
| **تثبيت جديد** | Live DB → `%LOCALAPPDATA%\GalaxyCashier\data\cashier.db` |
| **جهاز موجود (Documents فيه DB)** | يُبقى Documents كما هو — **بدون نقل** (تحذير OneDrive فقط إن لزم) |
| **Backups** | دائمًا `Documents\CASR-Backups` |
| **OneDrive** | تحذير فقط — **لا** منطق نقل تلقائي |
| **وصول Prisma عند مسافات/عربي** | `mklink /J` من `C:\ProgramData\GalaxyCashier\live` → مجلد الـ DB الحي (ACL مقيّد: مستخدم + Administrators + SYSTEM). **ليست** مرآة نسخ |

### مقارنة LocalAppData vs ProgramData (للـ DB الحية)

| | LocalAppData (المختار للتثبيت الجديد) | ProgramData (+ ACL مقيّد) |
|--|--|--|
| مسافات في المسار | نعم إذا اسم المستخدم فيه مسافة | عادة لا (`C:\ProgramData\...`) |
| عزل المستخدمين | DB لكل مستخدم Windows | مشتركة على الجهاز |
| صلاحيات | ملكية المستخدم افتراضيًا | تحتاج `icacls` لتقييد الوصول |
| بقاء بعد مسح البروفايل | لا | نعم |
| Prisma بدون junction | قد يحتاج junction | غالبًا مسار نظيف |

**المطبق الآن:** Live في LocalAppData للتثبيت الجديد؛ junction تحت ProgramData للوصول فقط عند الحاجة.  
إذا فضّلت **ProgramData كمكان حيّ للـ DB** بدل LocalAppData، أكّد ذلك لنبدّل الافتراضي.
