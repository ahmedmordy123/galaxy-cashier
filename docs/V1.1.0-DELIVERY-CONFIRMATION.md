## قرارات المسارات (نهائية)

| | Setup (NSIS) | Portable |
|--|--|--|
| **Live DB** | `C:\ProgramData\GalaxyCashier\data\cashier.db` (قاعدة واحدة لكل جهاز) | `%LOCALAPPDATA%\GalaxyCashier\data` (+ تحذير: لمستخدم ويندوز واحد) |
| **Backups الافتراضي** | `C:\ProgramData\GalaxyCashier\backups` | نفس الافتراضي الآلي إن وُجد ProgramData؛ وإلا عبر `CASR_BACKUP_DIR_DEFAULT` |
| **مسار ثانٍ خارجي** | اختياري (فلاشة) + تنبيه في الإعدادات إن غير مضبوط / غير متاح | نفس السلوك |
| **Prisma / مسافات** | مسار ثابت بلا مسافات — **بدون** junction / 8.3 / hardlink | junction فقط إن احتُيج (مسافات/عربي في LocalAppData) |
| **OneDrive** | تحذير فقط إن بقي مسار Documents حيّاً (Portable legacy) — **لا** نقل تلقائي | |
| **Uninstall** | **لا يمسح** `data` ولا `backups` | N/A |
| **Upgrade فوق قديم** | يحافظ على الداتا في ProgramData | |

### ACL عند Setup (`installer.nsh`)

```
SYSTEM + Administrators = Full
BUILTIN\Users = Modify (OI)(CI)
```

حتى حساب الكاشير العادي يقرأ/يكتب نفس الـ DB.

## 1هـ) Uninstall / Upgrade يحافظ على الداتا

`scripts/qa-v11-uninstall-preserve.cjs` → `docs/QA-V11-UNINSTALL-PRESERVE.json` — **11/11**

## 1و) حسابان ويندوز (أدمن + عادي)

`scripts/qa-v11-two-user-acl.cjs` → `docs/QA-V11-TWO-USER-ACL.json` — **13/13** (elevated + `GalaxyCashierTest`)

- ACL: SYSTEM/Admins Full + Users Modify
- حساب عادي كتب فعليًا تحت `ProgramData\GalaxyCashier\data` عبر `Start-Process -Credential`
- ماركر مشترك يظهر بين الجلسات + Restore فوري

إعادة التشغيل:

```powershell
# PowerShell Administrator
$env:GALAXY_TEST_USER = 'GalaxyCashierTest'
$env:GALAXY_TEST_PASS = 'TestPass123!'
Set-Location E:\CASR
node scripts/qa-v11-two-user-acl.cjs
```
