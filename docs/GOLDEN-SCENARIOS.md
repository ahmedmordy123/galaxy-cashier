# Golden accounting scenarios (يدوي → اختبار ثابت)

العملة: جنيه مصري. **التقريب على إجمالي الفاتورة لقرشين** (half-up).  
المرتجع الكامل لمجموع القطع = إجمالي الفاتورة الأصلية بالظبط (بدون فرق قرش).

- شاملة (Inclusive): `tax = afterDiscount × rate/(100+rate)` و `total = afterDiscount`
- مضافة (Exclusive، بعد الخصم): `net = afterDiscount` ، `tax = net × rate%` ، `total = net + tax`
- الربح = **الصافي بدون ضريبة** − COGS (الضريبة ليست من الربح)

---

## G0 — معتمد من صاحب المنتج (ضريبة مضافة + خصم + مرتجع)

| بيان | قيمة |
|------|------|
| تكلفة الوحدة | 100 |
| بيع | 130 × 2 = **260** |
| خصم فاتورة 10% | 26 → صافي **234** |
| ضريبة مضافة 14% | **32.76** |
| الإجمالي | **266.76** |
| الربح | 234 − 200 = **34** |
| مرتجع قطعة واحدة | صافي 117 + ضريبة 16.38 = **133.38** |
| مرتجعان كاملان | 133.38 × 2 = **266.76** ✅ |

اختبار رياضيات: `scripts/qa-golden-vat-exclusive-math.cjs` → 9/9.

## G1 — بيع نقدي + خصم ثابت + ضريبة 14%

| بيان | قيمة |
|------|------|
| بند | 2 × 100.00 = **200.00** (subtotal) |
| تكلفة الوحدة | 40.00 → COGS = **80.00** |
| خصم فاتورة FIXED | **20.00** |
| بعد الخصم = الإجمالي | 200 − 20 = **180.00** |
| ضريبة مستخرجة | 180 × 14 / 114 = **22.105263… ≈ 22.11** |
| مجمل الربح | 180 − 80 = **100.00** |
| نقدية الصندوق (CASH in) | **180.00** |
| مخزون بعد البيع | stock − 2 |

## G2 — مرتجع جزئي مع خصم نسبة 10%

| بيان | قيمة |
|------|------|
| بنود | A: 1×100 + B: 1×100 → subtotal **200.00** |
| خصم PERCENT | **10%** |
| إجمالي الفاتورة | 200 × 0.9 = **180.00** |
| مرتجع كامل للبند A (حصة خط 100) | 100 × 0.9 = **90.00** يسترد للعميل |
| المتبقي (B) | 100 × 0.9 = **90.00** |
| ضريبة على المتبقي (14%) | 90 × 14/114 ≈ **11.05** |
| مخزون A | +1 عند المرتجع |

## G3 — بيع آجل + تسديد جزئي

| بيان | قيمة |
|------|------|
| بند | 1 × 200.00، بدون خصم، ضريبة 0% للاختبار |
| نوع الدفع | CREDIT |
| رصيد العميل بعد التأكيد | **+200.00** |
| سند قبض جزئي | **50.00** |
| رصيد العميل بعد القبض | **150.00** |
| أثر الصندوق عند إقفال الوردية | +**50.00** إيصال (مع مبيعات G1/G2/G4) |

## G4 — خصم ثابت + مرتجع جزئي (توزيع الخصم)

| بيان | قيمة |
|------|------|
| بنود | 2 × 100 = **200.00** |
| خصم FIXED | **50.00** |
| إجمالي | 200 − 50 = **150.00** |
| مرتجع نصف الكمية (خط subtotal 100 من 200) | حصة المرتجع = 150 × (100/200) = **75.00** |
| المتبقي الصحيح | 150 − 75 = **75.00** |
| خصم FIXED المتبقي المخزَّن | 50 × (100/200) = **25.00** |
| خطأ قديم لو أُعيد تطبيق 50 على المتبقي 100 | كان يعطي 50 ❌ |
